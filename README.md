Agent Flow:

The user will first create their profile and enter their preferred sector in which they want to invest. They will have to specify what kind of investor they are(long term, short term, bullish, bearish)

Based on the user profile, and current stock scenario, the Company Shortlisting Agent will retrieve a certain number of potential stocks.

The Data Ingestion Agent will retrieve the stock information and news information for the shortlisted companies.

The Sentiment Analysis Agent will then perform sentiment analysis on the retrieved news data, and the Technical Analysis Agent and Prediction Agent (ML Model) will perform predictions on the stock data

All this information from the Sentiment, Technical, and Prediction agents will then be processed by the Portfolio Manager Agent, who will make the decision
